Everything a deploy should be

      

        

          
One command

          
Project detection, build, upload, URL. No dashboards, no drag-and-drop.

        

        

          
Interactive UI

          
A real terminal menu, arrow-key pickers, and masked token entry — zero dependencies.

        

        

          
Instant rollback

          
Immutable deploys behind a mutable alias. Roll back in seconds, not re-deploys.

        

        

          
Preview deploys

          
deploy preview ships a branch to its own URL — production untouched.

        

        

          
Five targets

          
Local control plane, Netlify, Vercel, Cloudflare Pages, and S3 from the same commands.

        

        

          
CI-safe

          
No prompts in scripts, pure JSON output, retries with backoff, idempotent uploads.

        

      

    


    

      
Ship anywhere

      

        
localbundled control plane

        
netlifydigest uploads · restore

        
vercelSHA1 uploads · rollback

        
cloudflarePages direct upload

        
s3SigV4 signed puts

      

      

        Live-verified on every release: netlify ✔ ·
        vercel ✔ · cloudflare ✔ ·
        s3 ✔ — each provider is smoke-deployed, content-checked,
        and rolled back against the real host (how it's tested), and the
        release workflow cleans the artifacts up afterwards.
